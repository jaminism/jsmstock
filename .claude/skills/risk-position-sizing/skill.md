# Risk & Position Sizing — 포지션사이징·리스크한도 방법론

risk-manager 에이전트(및 fund-manager의 포지션 설계)의 리스크 관리 역량을 강화하는 전문 스킬.

## 적용 대상 에이전트

- **risk-manager** — 리스크 한도 검증, 최종 승인
- **fund-manager** — 포지션 사이징 설계 시 참고

## 포지션 사이징 방법론

### 고정비율 방식 (가장 보편적, 기본 권장)
```
1회 최대 손실 허용액 = 총자산 × 리스크 허용비율(통상 1~2%)
매수 수량 = 1회 최대 손실 허용액 / (진입가 - 손절가)
```
→ 종목별 변동성과 무관하게 "이 거래가 실패했을 때 전체 자산에서 잃는 비율"을 일정하게 통제한다.

### ATR 기반 변동성 조정 사이징
```
손절폭 = ATR(14) × N배 (통상 N=1.5~2)
매수 수량 = 1회 최대 손실 허용액 / 손절폭
```
→ 변동성이 큰 종목은 자동으로 비중이 작아지고, 변동성이 작은 종목은 비중이 커진다.

### Kelly Criterion (이론적 상한, 실무에서는 절반 이하로 축소 적용 권장)
```
f* = W - [(1-W)/R]
  f* = 베팅 비율, W = 승률, R = 손익비(평균이익/평균손실)
```
| 사용 원칙 | 이유 |
|----------|------|
| Full Kelly는 사용하지 않음 | 승률/손익비 추정 오차 시 파산 위험 급증 |
| Half Kelly(f*/2) 이하 권장 | 추정 오차에 대한 안전마진 확보 |
| 승률·손익비 추정이 불확실할 때 | Kelly 대신 고정비율 방식으로 대체 |

## 손절 규칙 설계 원칙

| 방식 | 기준 | 적합 상황 |
|------|------|----------|
| 가격 기준 | 진입가 대비 -X% | 단순 명확, 변동성 미반영 |
| 변동성 기준(ATR) | 진입가 - ATR×N | 종목별 변동성 반영, 권장 |
| 구조적 기준 | 직전 저점/지지선 하회 | 기술적 분석과 연계, technical-analyst 산출물 활용 |
| 시간 기준 | N일 내 예상 시나리오 미실현 시 청산 | 이벤트 드리븐 전략 |

**원칙**: 모든 포지션은 진입과 동시에 손절가를 확정한다. "지켜보다가 정하겠다"는 계획은 리스크 관리 실패로 간주하고 🔴 처리한다.

## 집중도 한도 (일반적 가이드라인, 투자자 성향에 따라 조정)

| 위험 성향 | 단일 종목 최대 비중 | 단일 업종 최대 비중 | 현금 최소 비중 |
|----------|-------------------|-------------------|---------------|
| 보수적 | 10% 내외 | 25% 내외 | 20% 이상 |
| 중립 | 15~20% | 30~35% | 10% 내외 |
| 공격적 | 25~30% | 40% | 0~10% |

- 상관관계가 높은 종목(동일 업종, 동일 테마)들은 **실질적으로 하나의 포지션**처럼 취급하여 합산 비중을 점검한다
- 위 수치는 절대 규칙이 아닌 참고 가이드라인이며, 투자자 프로필에 맞게 조정하고 그 근거를 명시한다

## VaR (Value at Risk) 개념 적용

```
간이 VaR(95% 신뢰수준) ≈ 포지션 가치 × 변동성(연환산 표준편차) × 1.65 × sqrt(보유기간/연간거래일)
```
→ 정밀 계산보다는 "이 포트폴리오가 통상적 시장 상황에서 특정 확률로 얼마까지 손실 볼 수 있는가"를 투자자에게 직관적으로 전달하는 용도로 사용한다.

## 낙폭(Drawdown) 관리

| 낙폭 수준 | 대응 |
|----------|------|
| -10% | 포지션 재점검, 신규 진입 보수화 |
| -20% | 손실 포지션 축소 검토, 신규 진입 중단 |
| -30% 이상 | 전면 재평가, 전략 유효성 재검증 |

레버리지/신용거래 사용 시 낙폭 관리 기준을 더 보수적으로 설정해야 하며, risk-manager는 레버리지 존재 시 반드시 별도 경고를 산출물에 포함한다.

## 리스크 검증 시 자주 발견되는 위반 패턴 (🔴 처리 기준 예시)

- 손절가 미설정 포지션
- 단일 종목 비중이 투자자 위험 성향 한도를 명확히 초과
- 상관관계 높은 종목들의 합산 비중이 과도함에도 "분산됐다"고 서술
- 레버리지/신용 사용 시 낙폭 관리 계획 부재
- 손익비 또는 승률 추정 없이 "무조건 수익나는 전략"으로 서술
