# Backtesting Framework — 백테스팅·팩터투자 방법론

quant-strategist 에이전트의 매매기법 연구·전략 설계 역량을 강화하는 전문 스킬.

## 적용 대상 에이전트

- **quant-strategist** — 매매기법 규칙화, 팩터 스크리닝, 백테스팅 설계

## 팩터 투자 프레임워크

| 팩터 | 정의 | 대표 지표 | 이론적 근거 |
|------|------|----------|------------|
| 모멘텀 | 최근 상승 추세가 지속되는 경향 | 3/6/12개월 수익률 | 투자자 과소반응/처분효과 |
| 밸류 | 저평가 자산의 초과수익 경향 | PER, PBR, EV/EBITDA (낮을수록 유리) | 평균회귀, 리스크 프리미엄 |
| 퀄리티 | 재무 우량 기업의 안정적 초과수익 | ROE, 부채비율, 이익변동성 | 우량기업 저평가 경향 |
| 사이즈 | 소형주의 장기 초과수익 경향(시기별 편차 큼) | 시가총액 | 유동성 프리미엄, 정보 비대칭 |
| 로우볼 | 저변동성 종목의 위험조정수익 우위 | 과거 변동성(표준편차), 베타 | 저변동성 이상현상 |

**팩터 결합 시 원칙**: 단일 팩터보다 2~3개 팩터를 결합(멀티팩터)할 때 안정성이 높아지는 경향이 있으나, 팩터 간 상관관계(예: 밸류와 모멘텀은 역상관 경향)를 고려해야 한다.

## 매매기법 유형별 규칙 설계 템플릿

### 추세추종(Trend Following)
```
진입: N일 신고가 돌파 + 거래량 동반 + 상위 추세지표(이평 정배열) 확인
청산(손절): 진입가 대비 -X% 또는 ATR × N배 역행 시
청산(익절): 트레일링 스탑(고점 대비 -Y% 하락 시) 또는 추세 반전 신호 시
적합 국면: 추세장(강세/약세 모두 가능, 방향 무관)
취약 국면: 횡보장(휩쏘 빈발)
```

### 평균회귀(Mean Reversion)
```
진입: 볼린저밴드 하단 이탈 + RSI 과매도 + 펀더멘털 훼손 없음 확인
청산(손절): 추가 하락 시 -X% 또는 이탈 폭 확대 시
청산(익절): 이동평균 회귀 시 또는 밴드 중단선 도달 시
적합 국면: 횡보장, 낮은 변동성
취약 국면: 강한 추세장(계속 하락하는 "떨어지는 칼날")
```

### 브레이크아웃
```
진입: 삼각수렴/박스권 상단 돌파 + 거래량 급증
청산(손절): 돌파 실패(재진입) 시 즉시
청산(익절): 패턴 목표가(높이 투영) 도달 또는 분할 익절
적합 국면: 변동성 확대 전조 국면
취약 국면: 가짜 돌파(false breakout) 빈발 구간
```

### 페어트레이딩(통계적 차익거래)
```
진입: 상관관계 높은 두 종목의 스프레드가 평균 대비 N 표준편차 이탈 시 (롱-숏 동시 진입)
청산: 스프레드가 평균으로 회귀 시
적합 국면: 시장 방향성과 무관 (시장중립 전략)
리스크: 상관관계 구조적 붕괴(펀더멘털 변화) 시 손실 확대
```

## 백테스팅 설계 절차

```
1. 가설 수립: "왜 이 기법이 초과수익을 낼 것으로 기대하는가" 이론적 근거 명시
2. 유니버스 정의: 검증 대상 종목/기간 범위
3. 규칙 명세화: 진입/청산/포지션사이징을 모호함 없이 수치화
4. In-sample 구간 설정: 전체 기간의 60~70%
5. Out-of-sample 구간 설정: 나머지 30~40% (전략 확정 후 1회만 검증, 반복 조정 금지)
6. 거래비용 반영: 수수료, 슬리피지, 세금(해당 시) 가정을 명시
7. 성과지표 산출 및 벤치마크 대비 비교
```

## 핵심 성과지표

| 지표 | 산식/정의 | 해석 |
|------|----------|------|
| CAGR | 연평균 복리 수익률 | 절대 수익률 |
| 샤프비율 | (수익률-무위험수익률)/변동성 | 1 이상 양호, 2 이상 우수 (일반적 기준) |
| MDD (최대낙폭) | 고점 대비 최대 하락폭 | 감내 가능 손실 수준과 비교 |
| 승률 | 이익 거래 수 / 전체 거래 수 | 손익비와 함께 봐야 함 (승률 낮아도 손익비 높으면 우수 가능) |
| 손익비(Payoff Ratio) | 평균 이익 거래 / 평균 손실 거래 | 1.5 이상이면 승률 40%대에서도 기대수익 플러스 가능 |
| 칼마 비율 | CAGR / MDD | 낙폭 대비 수익 효율성 |

## 과최적화(Overfitting) 방지 체크리스트

- [ ] 파라미터 수가 3~4개를 크게 넘지 않는가 (많을수록 과적합 위험)
- [ ] 파라미터를 소폭 변경해도 성과가 급격히 무너지지 않는가 (안정성 확인)
- [ ] Out-of-sample 성과가 In-sample 대비 현저히 낮지 않은가
- [ ] 특정 소수 종목/특정 급등구간에만 성과가 의존하지 않는가
- [ ] 검증 기간에 상승장/하락장/횡보장이 고루 포함되는가
- [ ] 생존편향(상장폐지 종목 제외 등)이 결과를 왜곡하지 않는가

## Walk-Forward 검증 개념

```
전체 기간을 여러 구간으로 分할 → 각 구간에서 (학습구간에서 파라미터 최적화) → (다음 검증구간에 적용) 을 반복 이동
→ 특정 단일 구간에 과최적화되는 것을 방지하고, 시간에 따른 강건성(robustness)을 확인
```

## 유의사항

이 스킬은 백테스팅의 **설계 방법론**을 제공한다. 실제 과거 시세 데이터를 이용한 코드 실행·수치 산출은 사용자가 별도의 데이터/도구(예: Python 백테스팅 라이브러리)로 수행해야 하며, quant-strategist는 그 실행 계획과 해석 기준까지를 산출물로 제공한다.
