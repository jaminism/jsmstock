# Equity Valuation Methods — 기업가치평가 방법론

fundamental-analyst 에이전트의 기업분석·밸류에이션 역량을 강화하는 전문 스킬.

## 적용 대상 에이전트

- **fundamental-analyst** — 밸류에이션 산출, 재무비율 분석, 목표주가 도출

## 상대가치 밸류에이션 (Multiple 기반)

| 지표 | 산식 | 적합 대상 | 주의점 |
|------|------|----------|--------|
| PER | 주가 / EPS | 이익 발생 기업 전반 | 적자 기업 산출 불가, 일회성 손익 제외한 정상화 EPS 사용 |
| PBR | 주가 / BPS | 금융/자산 중심 업종 | 자산 재평가 여부, ROE와 함께 해석 (PBR = PER × ROE 근사) |
| PEG | PER / EPS성장률(%) | 성장주 | 1 이하=저평가 시사, 성장률 추정의 신뢰도가 관건 |
| EV/EBITDA | (시가총액+순차입금) / EBITDA | 감가상각 큰 업종(장치산업 등), 자본구조 다른 기업 비교 | 부채 수준 반영, CAPEX 미반영 한계 |
| EV/Sales(PSR) | EV / 매출액 | 적자·초기 성장기업 | 마진 구조 무시하는 한계, 동일 산업 내에서만 비교 |
| 배당수익률 | 주당배당금 / 주가 | 배당주, 가치주 | 배당성향·배당 지속가능성 함께 확인 |

### Peer(비교기업) 밸류에이션 절차

```
1. 산업·사업모델·규모가 유사한 기업 3~5개 선정
2. 각 기업의 PER/PBR/EV-EBITDA 등 수집
3. 이상치(적자, 특수 이벤트 기업) 제외 후 중위값/평균 산출
4. 대상 기업의 실적 추정치에 Peer 멀티플 적용하여 목표가 산출
5. 대상 기업 고유의 프리미엄/디스카운트 요인(성장성, 지배구조 등) 반영해 조정
```

## 절대가치 밸류에이션 (DCF 개요)

간이 DCF 절차 (상세 WACC/FCFF 산정은 별도 요청 시 심화):

```
1. 향후 3~5개년 잉여현금흐름(FCF) 추정
2. 할인율(WACC) 적용해 현재가치 산출
3. 영구성장률 또는 Exit Multiple로 터미널 밸류 산출
4. 기업가치(EV) - 순차입금 = 주주가치 → 주당가치
```

DCF는 가정에 대한 민감도가 크므로, **반드시 Multiple 방식과 교차 검증**하여 밸류에이션 범위(range)로 제시한다.

## 재무비율 분석 프레임워크

### 수익성
| 지표 | 산식 | 해석 |
|------|------|------|
| 매출총이익률 | 매출총이익/매출액 | 가격결정력, 원가구조 |
| 영업이익률 | 영업이익/매출액 | 본업 수익성 |
| ROE | 순이익/자기자본 | 주주자본 효율성 |
| ROA | 순이익/총자산 | 자산 효율성 |

### 듀퐁분석 (ROE 분해)
```
ROE = 순이익률 × 총자산회전율 × 재무레버리지
    = (순이익/매출) × (매출/총자산) × (총자산/자기자본)
```
ROE가 높아도 재무레버리지(부채) 기여가 큰 경우, 수익성의 질을 별도로 평가한다.

### 안정성
| 지표 | 산식 | 통상 기준 |
|------|------|----------|
| 부채비율 | 부채총계/자기자본 | 100% 이하 양호(업종별 상이, 금융업 등 예외) |
| 유동비율 | 유동자산/유동부채 | 150% 이상 양호 |
| 이자보상배율 | 영업이익/이자비용 | 3배 이상 양호, 1배 미만은 이자 지급 능력 위험 |

### 성장성
| 지표 | 산식 |
|------|------|
| 매출액증가율 | (당기매출-전기매출)/전기매출 |
| 영업이익증가율 | (당기영업이익-전기영업이익)/전기영업이익 |

## 실적 시즌 체크포인트

- **어닝서프라이즈/쇼크**: 실제 실적 vs 컨센서스 괴리율 (통상 ±10% 이상이면 유의미)
- **가이던스 변화**: 회사 측 향후 실적 전망 상향/하향 여부
- **일회성 항목**: 자산매각손익, 손상차손 등 정상화 이익과 분리해 해석

## 산업별 밸류에이션 참고 경향 (일반론, 시점별 변동 가능성 명시 필요)

| 산업 | 주로 쓰이는 지표 | 특징 |
|------|----------------|------|
| 성장/IT/플랫폼 | PSR, PEG, EV/EBITDA | 이익 미실현 구간 많음 |
| 금융/은행 | PBR, ROE | 자산건전성이 핵심 |
| 장치산업(반도체/화학 등) | EV/EBITDA, PBR | 감가상각·설비투자 부담 큼, 업황 사이클 고려 |
| 바이오/제약 | PSR, 파이프라인 가치(rNPV) | 이익 발생 이전 단계가 많음 |
| 소비재/유통 | PER, EV/Sales | 브랜드력, 회전율 중요 |

이 표는 일반적 경향이며, 실제 적용 시 최신 업종 평균과 반드시 교차 확인해야 함을 명시한다.
