# Step 2 — K2기법

## 1. 기법 개요

**K2기법**은 "상한가(대량 거래대금 동반) 이후 조정(눌림목) 국면에서 피보나치 되돌림 50% 구간을 노리는 리바운드(반등) 매수 기법"이다. 강사(종산)의 "저녁교육강의" 시리즈 제3장 "K2매매" 및 강사 커뮤니티(royalroader.co.kr) 배포 수식 자료 기준.

- **이름 유래**: 피보나치 되돌림선 0.236 = "K1", 되돌림선 0.5 = "K2". 즉 K1/K2는 피보나치 레벨 이름 자체가 매매기법 이름이 된 경우.
- **핵심 아이디어**: 상한가(하루 상한폭까지 급등, 한국시장 특유의 가격제한폭 제도)를 기록한 종목은 시장의 관심이 집중되므로, 이후 조정 시 특정 되돌림 구간(50%)에서 매수 주체(주포)의 지지가 들어올 가능성이 높다는 경험칙에 기반.
- 1기(초기 버전)에는 RSI 과매도 시점을 수동으로 차트에서 찾아 피보나치 기준점으로 삼았으나, RSI 기반 자동화 시 오류가 잦아 2기부터는 "상한가 발생 후 N일간의 최저가"를 자동 산출하는 수식으로 개선됨.

## 2. 핵심 진입/청산 규칙

**이론 자료(K2이론강의.pdf) 원문 규칙 4개:**
1. 500억 원 이상의 거래대금을 동반한 상한가 출현 시, 상한가 직전 RSI 과매도 지점에서 상한가 당일 최고점까지 피보나치선을 긋는다 (5분봉 기준).
2. 0.236선을 "K1"이라 부른다.
3. 0.5선을 "K2"라 부른다.
4. **K2선이 훼손(하향 이탈)될 때 장중 매수**한다.
5. 매수 가능 기간은 **고점 갱신일 포함 4일차까지**로 제한한다 (그 이후는 기법 유효성 상실로 간주).

**실전 자료(182페이지 복기 로그)에서 확인된 추가 재량 규칙 — 자동매매 구현 시 반드시 필요한 "정성적 필터":**

| 상한가 유형 | K1 | K2 | 비고 |
|------------|----|----|------|
| 정상 상승 후 상한가 | 가능 | 가능 | 가장 안전한 패턴 |
| 짧은N자형 상한가 (급등형) | **금지** | 가능 | K1은 되돌림이 얕아 리스크 대비 보상 부족 |
| 긴N자형 상한가 (완만한 상승 후 상한가) | **전부 금지** | **전부 금지(원칙)** | "설거지"(세력의 물량 매도) 의심 구간 |
| 긴N자형이지만 거래대금 5천억~7천억 이상 시장중심주 | 예외적으로 가능 | 예외적으로 가능 | "구분하기 힘들면 원칙 준수(하지 않는다)"가 기본값 |

- **테마 내 순위 필터**: 동일 테마(예: 쿠팡 관련주, 루시드 관련주, 비트코인 테마)에서 상한가가 여러 개 나올 경우, 테마를 주도하는 **1등주만 채택**하고 2등주·3등주·꼴등주는 "안함"으로 스킵하는 사례가 로그 전반에서 매우 빈번하게 관찰됨 — 수식만으로는 포착 불가능한 규칙.
- **가격대 필터 (하한 리스크)**: K2 되돌림선이 상한가 대비 약 -27% 수준까지 내려오는 경우, 한국 시장의 하한가(-30%)가 코앞이므로 매수 회피. 오후장에 -25% 이상 밀린 종목은 반등 확률이 낮고 패닉성 하한가로 이어질 위험이 있어 회피.
- **3연상 이상(3상 이상) 특수 규칙 — "서비스매매"**: 상한가가 3번 이상 연속된 경우, 가장 최근 상한가가 아니라 **그 직전(1상 위) 상한가를 기준점**으로 피보나치선을 다시 긋는다.
- **눌림목 확인**: "거래량이 줄어든 구간이 저점(진입 시작점)" — RSI 신호에만 의존하지 말고 거래량 감소 구간을 응용 판단 근거로 사용.
- **매수 근거 강도**: 시장의 관심(거래대금, 인기순위)이 클수록 원칙에서 벗어난 예외(긴N자, 무공방상한가 등)도 성공 확률이 높아진다고 강사가 반복 언급 — 즉 이 기법은 순수 가격 패턴이 아니라 "시장 참여자들의 관심 집중도"에 의존하는 자기실현적(self-fulfilling) 성격이 강함.

## 3. 검색식/스크리닝 공식 (원문 인용)

HTS(홈트레이딩시스템) 조건검색식 언어(대신증권 CYBOS Plus 계열로 추정) 원문:

```
D  = CountSince(상한가체크(1), Date != Date(1));
DX = valuewhen(1, 상한가체크(1), max(dayhigh(), predayhigh()));
기준봉 = dayOpen()*1.08 <= dayclose();   // v2에서 추가된 보조 판정 (8% 이상 장대양봉)

HH2 = max(predayhigh(), npredayhigh(2), npredayhigh(3), npredayhigh(4), npredayhigh(5), npredayhigh(6));
HH  = max(dayhigh(), HH2);

SBB = CountSince(기준봉 and !UL(), Date != Date(1));   // v2: 상한가 아닌 8%+ 장대양봉 이후 경과일
HD  = CountSince(HH2 <= dayhigh(), Date != Date(1));

DL2 = if(SBB <= 3,
         LowestSince(1, UL(), min(daylow(), npredaylow(1), npredaylow(2))),
         LowestSince(1, UL(), min(daylow(), npredaylow(1), npredaylow(2), npredaylow(3), npredaylow(4), npredaylow(5))));

DLL = if(상한가체크(1), DL2,
       if(상한가체크(2), DL2,
        if(상한가체크(3), DL2,
         if(상한가체크(4), DL2,
          if(상한가체크(5), DL2,
           if(상한가체크(6), DL2,
            if(상한가체크(7), DL2, DL2)))))));

K1 = (DX - DLL) * (1 - 0.236) + DLL;     // 76.4% 되돌림 지점 (얕은 되돌림)
K2 = (DX - DLL) * (1 - 0.5) + DLL;       // 50% 되돌림 지점 (기본)

// 최종 K2 (조건부):
K2 = if(D < 2,
        (DX - DLL) * (1 - 0.5) + DLL,
        if(D >= 2 and HD < 4 and D < 7,
           (HH - DLL) * (1 - 0.5) + DLL,
           0));  // 조건 미충족 시 신호 없음(0)

K1신호 = if(D < 2, K1, 0);   // K1은 상한가 발생 후 1일 이내에서만 유효
K2추매 = K2 * K2추매배수;    // 추가매수(피라미딩) 변형
```

**상한가/하한가 판정 보조 수식** (한국 시장 가격제한폭 및 호가단위 규칙 반영, 자동매매 구현 시 필수):

```
// 상한가 판정
A1 = if(date < 20150615, (PreDayClose()*15)/100, (PreDayClose()*29.73)/100);  // 2015-06-15 이전 ±15%, 이후 ±30%
A2 = A1 + PreDayClose();
A  = [A2를 호가단위(1000원미만 1원, 5000원미만 5원, 1만원미만 10원, 5만원미만 50원,
      10만원미만 100원, 50만원미만 1000원, 이상 1000원 단위)로 내림(floor) 처리];
상한가여부 = floor(A) <= 종가;

// 하한가 판정 (동일 로직, 반대 방향 + 올림(ceil) 처리, 계수 30 사용)
```

- 위 상/하한가 로직은 **2015-06-15 가격제한폭 확대(±15%→±30%) 이전/이후를 분기 처리**하고 있어, 과거 백테스트 시 이 분기점을 반드시 반영해야 함.
- 호가단위(tick size) 규칙은 한국거래소 규정에 따른 것으로, 정확한 상한가/하한가 자동 판정에 필수.

## 4. 계산기(xlsx) 로직

`K1_K2_수동계산기.xlsx`: 자동 수식이 어려운 수강생을 위한 수동 보조 계산기.

| 셀 | 내용 | 수식 |
|----|------|------|
| B3 | 최고값(고점, 원문 라벨 "최고RSI값"이나 실제는 DX/HH에 해당하는 고점가) | 입력값 |
| B4 | 최저값(저점, 원문 라벨 "최저RSI값"이나 실제는 DLL에 해당하는 저점가) | 입력값 |
| C3 (K1) | = B3-((B3-B4)*0.236) | 76.4% 되돌림가 |
| D3 (K2) | = B3-((B3-B4)/2) | 50% 되돌림가 |

라벨은 "RSI값"으로 되어있지만 실제로는 1기(RSI 기반)의 잔재 표현이며, 2기 이후에는 고점(DX/HH)·저점(DLL) 값을 수동으로 입력해 동일한 피보나치 계산을 수행하는 용도로 쓰인다.

## 5. 실전 사례 요약 (2021년 1~2월 복기 자료 182페이지 기반)

- 하루 평균 5~10개 종목의 상한가를 스캔하며, 각 종목에 "종목명/판정(K2 등)/사유"를 태깅하는 방식으로 매일 복기.
- **판정 태그 분포 예시**: "K2"(진입), "안함/날짜"(기간 초과), "안함/단기과열", "안함/긴N자상한가", "안함/2등주"(3등주)", "안함/악재발생", "안함/재료없음", "손절", "본절"(손익 0 청산) 등.
- **매우 빈번한 스킵 사유**: 동일 테마 내 후발주(2등주/3등주/꼴등주), 긴N자형 상한가, 날짜(4일 초과) 경과.
- **예외적으로 긴N자에도 진입한 사례**: "삼성출판사" — 1상 거래대금 3천억, 2연상 거래대금 5천억에 육박한 자타공인 시장중심주였기에 원칙(긴N자 회피)을 깨고 진입. 강사는 이를 "언젠가는 구분하고 할 수 있게 된다"는 숙련 필요 영역으로 언급.
- **비교 사례**: "다날"(1등주, 점상 유지) vs "갤럭시아머니트리"(2등주, 다날이 견고할 때 무너짐, 종가가 장중 최저에 마감) — 1등주의 눌림목에서 진입해야 한다는 교훈 사례로 반복 인용.

## 6. 강사가 강조한 주의사항 및 리스크

1. **"K2를 매수하면 안 되는 이유" (강사 원문 3가지)**:
   - K2 되돌림선이 -27% 수준이면 하한가(-30%)가 코앞이라 부적절
   - 오전장에 이미 20% 이상 K2 부근에서 선반등이 나왔다면 부적절 (이미 반등 소진)
   - 오후장에 -25% 이상 밀리면 반등 확률이 낮고, 물린 투자자들의 투매(하한가行)로 이어질 위험
2. **긴N자형 상한가는 "설거지"(작전 세력의 물량 처분) 의심 구간** — 원칙적으로 회피, 예외는 압도적 거래대금(시장중심주)일 때만.
3. **1기 수식(RSI 기반)의 한계**를 강사 스스로 인정 — "저도 수식 초보입니다", "이 수식도 완벽하지 않다", "매매하실 땐 수동 체크하시고 복기용으로 이용하세요" — **자동 신호를 맹신하지 말라는 반복적 경고**.
4. RSI 신호에 지나치게 얽매이지 말고 거래량 감소(눌림목) 등 응용 판단을 병행할 것을 강조.
5. 형식적으로 K2 조건을 충족해도 **테마 내 순위(1등주 여부)와 시장 관심도**가 실제 성공률을 좌우한다는 점을 반복 강조 — 순수 가격 기반 자동화의 한계.

## 7. 전문가 검토

### 7.1 technical-analyst 관점

**종합 신호 판정 방식으로서의 타당성**: K1/K2는 본질적으로 **피보나치 되돌림 + 거래량 확인**의 조합이며, 이는 표준적인 기술적 분석 프레임워크(`technical-indicator-library` 참고)와 부합한다. 다만 원 기법은 지지선 확정을 오직 피보나치 한 가지 도구에만 의존하고 있어, "최소 3개 이상의 지표·근거를 교차 확인"하는 원칙에는 미달한다.

- **보완 여지**: 되돌림 진입 시점에 RSI 과매도 재확인(다이버전스 포함), 거래량 지표(OBV 또는 당일 VWAP 대비 위치)로 매수세 전환 여부를 교차검증하면 신호 신뢰도가 높아진다. 실제로 강사도 "거래량 감소=눌림목 시작점"이라는 별도 필터를 비공식적으로 쓰고 있는데, 이를 OBV/거래량 이동평균 기준으로 정량화하면 자동화 가능하다.
- **차트 패턴 분류(긴N자 vs 짧은N자 vs 정상상승)**는 사실상 헤드앤숄더·이중천장 같은 표준 패턴 분류와 유사한 발상이나, 표준 패턴 카탈로그에는 없는 이 시장 특유의 패턴(상한가 직전 캔들 형태)이다. 이는 "직전 N일간 종가 위치의 표준편차/기울기"로 어느 정도 정량화할 수 있다 — 예: 상한가 이전 5일간 종가가 완만한 상승 기울기(작은 표준편차)를 보이면 "긴N자", 급격한 단일 캔들 상승이면 "짧은N자"로 분류.
- **다이버전스 미고려**: 상한가 자체가 이미 극단적 과매수 신호이므로, 상한가 이후 RSI가 얼마나 빠르게 정상 범위로 되돌아오는지(다이버전스 여부)를 추가 필터로 쓸 수 있음에도 원 기법은 명시적으로 다루지 않음.

### 7.2 quant-strategist 관점

이 기법은 `backtesting-framework` 스킬 기준으로 분류하면 **"평균회귀(Mean Reversion) + 이벤트 드리븐(상한가 이벤트)"의 하이브리드**다.

- **진입-청산-리스크관리 3요소 점검**:
  - 진입: K2선 하향 이탈 시 (명확, 규칙화 가능)
  - 청산(익절): **원 자료에 명시적 익절 규칙이 없음** — 재상한가 시 매도인지, HH 재돌파 시 매도인지 불명확. 자동매매 구현 시 반드시 보완 필요한 최대 공백.
  - 청산(손절): 복기 로그에 "손절", "본절" 태그만 있을 뿐 정량적 손절 기준(예: DLL 하회 시 -X%)이 텍스트로 명시되어 있지 않음.
- **팩터 관점 재해석**: "500억 이상 거래대금", "테마 내 1등주"는 사실상 **모멘텀 팩터 + 유동성 팩터**의 스크리닝 조건이다. 이를 정량 스크리닝 조건으로 변환하면:
  - 유니버스 필터: 당일 거래대금 ≥ 500억원 AND 당일 상한가(등락률 ≥ 29.5%)
  - 테마 순위 필터: 동일 테마 내 등락률/거래대금 순위 1위만 채택 (테마 그룹핑 로직 필요 — 뉴스/공시 기반 태깅이 필요해 순수 가격 데이터만으로는 구현 난이도가 높음)
- **재량 판단이 필요한 영역 (자동화 최대 난제)**: "긴N자 vs 짧은N자" 분류, "시장중심주 여부"(거래대금 5천억 기준이 고정 임계값인지 상대적 기준인지 불명확), "테마 리더십" 판정 — 이 세 가지는 모두 정성적 판단이며, 순수 규칙 기반 자동매매로 변환 시 상당한 오탐(false positive)이 예상됨.
- **백테스팅 설계 제안**:
  - 검증 기간: 최소 2015-06-15 전후(가격제한폭 변경) 각각 포함, 상승장(2020H2~2021 초)과 하락장(2021H2~2022) 모두 포함
  - 벤치마크: KOSDAQ 지수, 또는 상한가 종목 단순 매수·보유 대비
  - 성과지표: 승률, 손익비, MDD — 특히 "K2 매수 안 하는 이유 3가지"(하한가 근접, 선반등 소진, 오후 급락)를 사전 필터로 넣은 버전과 뺀 버전을 비교해 그 필터들의 실질 기여도를 검증해야 함
  - **과최적화 경고**: "복기"라는 방법론 자체가 사후적(hindsight)으로 성공 사례를 정당화하는 방식(예: 삼성출판사의 원칙 예외 허용)이므로, 실제 실시간(walk-forward) 조건에서는 재현되지 않을 위험이 매우 큼 — 반드시 아웃오브샘플 검증 필요.

### 7.3 risk-manager 관점

`risk-position-sizing` 스킬 기준 검토.

- 🔴 **필수 수정 — 손절 규칙 미확정**: 원 자료 어디에도 "K2 진입 후 몇 % 하락 시 손절"이라는 정량 규칙이 없다. "K2가 -27%대이면 매수 안 함"이라는 진입 필터는 있지만, 일단 진입한 이후의 손절 기준이 없는 것은 명백한 리스크 관리 공백. 자동매매 구현 시 **ATR 또는 DLL 대비 고정% 하회를 손절선으로 반드시 별도 정의**해야 한다.
- 🔴 **필수 수정 — 포지션 사이징 근거 부재**: "K2추매"(피라미딩) 변수가 수식에 존재하나 추가매수 배율이나 트리거 조건이 원문에 구체화되어 있지 않다. 추매 로직 없이 자동화하면 과도한 단일 종목 집중 위험.
- 🟡 **권장 — 개별 종목 리스크가 매우 높은 전략군**: 이 기법이 다루는 대상 자체가 "당일 상한가(29.5%+ 상승) 종목의 조정 국면 매수"로, 변동성이 극단적으로 큰 종목군이다. 하한가(-30%)까지 근접할 수 있다는 사실 자체가 이미 최대 손실폭이 -30%대에 이를 수 있음을 시사 — 포트폴리오 비중은 반드시 낮게(개별 종목당 5% 이하 권장) 제한해야 한다.
- 🟡 **권장 — 자기실현적 성격에 대한 경고**: 강사가 반복 강조하는 "시장 관심도가 높으면 예외적으로 원칙을 깨도 성공한다"는 서술은, 이 기법의 승률이 **다수의 다른 트레이더들이 동일한 피보나치 레벨을 보고 매수한다는 군중심리**에 상당 부분 의존함을 시사한다. 이는 시장 참여자 구성이 바뀌거나(예: 유사 기법 사용자 감소), 규제 변화(상한가 제도 변경) 시 전략 자체가 급격히 무력화될 수 있는 구조적 리스크다.
- 🟢 **참고 — 상/하한가 제도 자체가 한국 시장 특유의 구조**이므로, 이 기법은 미국·유럽 등 가격제한폭이 없는 시장에는 이식 불가능하다는 점을 명시해야 한다 (범위 제한).
- **낙폭 시나리오**: 하한가 근접 필터를 지키지 않고 진입한 포지션이 실제 하한가로 귀결되는 최악의 경우, 단일 포지션 기준 최대 -30% 손실이 하루 만에 발생할 수 있다. 포트폴리오 차원에서는 이런 포지션이 동시에 다수 발생하지 않도록(예: 동일 일자 신규 진입 종목 수 제한) 규칙화가 필요.

## 8. 자동매매 구현 시 고려사항 / 미해결 질문

1. **익절(청산) 규칙 완전 부재** — 가장 시급한 공백. HH 재돌파 시 익절인지, 목표 수익률 기반인지 사용자(전 수강생) 확인이 필요하거나, quant-strategist의 백테스팅으로 최적 청산 규칙을 별도 도출해야 함.
2. **정량적 손절 기준 부재** — DLL 하회 시 즉시 손절 등, 명시적 규칙 신규 설계 필요.
3. **"긴N자 vs 짧은N자" 자동 판정 로직 부재** — 가격 데이터만으로 근사 분류 알고리즘(예: 상한가 이전 N일 종가의 선형회귀 기울기·잔차)을 새로 설계해야 함. 완벽한 자동화는 어렵고 오탐 가능성을 인지해야 함.
4. **"테마 리더십(1등주 여부)" 판정 불가** — 뉴스/공시/테마 분류 데이터베이스 연동이 필요하며, 순수 가격·거래량 데이터만으로는 구현 불가능한 영역. 자동매매 1차 버전에서는 이 필터를 제외하거나, 거래대금 순위로 근사 대체하는 타협안 검토 필요.
5. **"시장중심주" 판정 임계값(5천억~7천억)**이 절대 기준인지 상대(당일 코스닥 전체 거래대금 대비 비율) 기준인지 원문에서 불명확 — 확인 필요.
6. **가격제한폭 변경(2015-06-15) 로직은 현재 시점 기준 항상 "이후"이므로 실거래 구현 시에는 단순화(고정 30%) 가능**하나, 과거 데이터 백테스트 시에는 분기 로직 유지 필요.
7. **상한가/하한가 자동 판정 시 호가단위 규칙**을 정확히 구현하지 않으면 상한가 진입/이탈 판정 자체가 어긋날 수 있음 — 원문 수식을 그대로 코드화하는 것을 권장 (재구현 시 재현 오류 위험).
