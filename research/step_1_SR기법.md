# Step 1 — SR기법 (상한가리바운딩)

## 1. 기법 개요

**SR** = 상한가리바운딩(上限價 리바운딩). "선취매"라고도 불린다. 강사 "종산"(7급 행정공무원 출신, 종가베팅 전문트레이더 컨셉)이 만든 5개 기법 시리즈(SR→K1→K2→K1+→K2+/SP) 중 첫 번째로 강의되는 입문 기법이다.

**핵심 아이디어**: 전일 상한가(당일 고가=당일 종가로 마감, 즉 "진짜" 상한가로 마감)를 기록한 종목이, 이후 며칠간 조정(눌림)을 받다가 상한가 가격과 전일 종가 사이의 등분선(지지선)에서 반등하는 것을 노리는 기법. 장중 실시간 대응보다 **예약매수(조건검색+자동주문)** 중심으로 설계되어 있어, 직장인도 실행 가능하도록 설계된 것이 특징이다.

## 2. 핵심 진입/청산 규칙

이론 강의자료(SR매매_이론.pdf, "상따보다 강력한 SR매매") 원문에 명시된 8단계 규칙:

1. 500억 이상의 상한가 종가와 **전일 종가**를 기준으로 3등분 선긋기
2. 상한가가격은 **R0**, 나뉘어진 첫번째선은 **R1**, 나뉘어진 두번째선은 **R2**, 전일종가는 **R3**라 칭한다
3. **R1에서 매수하여 R0까지 분할매도**
4. **상한가후 7일까지만 매수한다** (상한가일 비포함 7일)
5. 매수 후 **매수일포함 4일차에는 올매도**한다
6. 추가매수는 **R2에서 1:1매수**한다 (기존 물량과 동일 수량)
7. 추매시 **본절에 물량의 반을 매도**하고 나머지 물량은 수익매도
8. **R3까지 밀릴때 손절**

강사가 별도로 제시한 간이 버전(수강생 대상 완화 안내): "R1사서 R0파세요. 잘 안되면 R0.9에 사서 R0.2에 팔면 됩니다" — 즉 세밀한 그리드 계산 없이도 대략적 3등분 개념만으로 실행 가능하다는 취지.

## 3. 검색식/스크리닝 공식 (원문 인용)

증권사 HTS(수식관리자, 대신/이베스트류 포뮬러 문법) 기준 커스텀 지표로 구현.

**함수 UL() — 당일 상한가 판정**
```
(date < 20150615 and (dayhigh() == dayclose()) and
 ((if(dayclose()<5000,dayclose()+5, if(dayclose()<10000,dayclose()+10,
  if(c<50000,dayclose()+50, if(c<100000,dayclose()+100,
  if(c<500000,dayclose()+500,dayclose()+1000)))))) / PreDayClose() > 1.15))
or
(date >= 20150615 and (dayhigh() == dayclose()) and
 ((if(dayclose()<5000,dayclose()+5, if(dayclose()<10000,dayclose()+10,
  if(c<50000,dayclose()+50, if(c<100000,dayclose()+100,
  if(c<500000,dayclose()+500,c+1000)))))) / PreDayClose() > 1.3));
```
※ 2015/06/15 한국 주식시장 가격제한폭 확대(±15%→±30%) 전후를 분기 처리.

**함수 상한가체크(일) — 전일 상한가 여부 판정**
```
(nPreDayHigh(일) == nPreDayClose(일)) and
전일상한가 = (IF(nPreDayClose(일)<1000, nPreDayClose(일)+1,
              IF(nPreDayClose(일)<5000, nPreDayClose(일)+5,
              IF(nPreDayClose(일)<10000, nPreDayClose(일)+10,
              IF(nPreDayClose(일)<50000, nPreDayClose(일)+50,
              IF(nPreDayClose(일)<100000, nPreDayClose(일)+100,
              IF(nPreDayClose(일)<500000, nPreDayClose(일)+500, nPreDayClose(일)+1000)))))));
IF(Date >= 20150615, 전일상한가 / nPreDayClose(일+1) > 1.30,
                      전일상한가 / nPreDayClose(일+1) > 1.15);
```

**본식 — 상한가리바운딩 R0~R3 (지표조건: 대금=500, 기간=7)**
```
P = volume * ((o+h+l+c)/4) / 10000 / 10000;   // 근사 거래대금(억원 단위)
Q = sum(P);                                    // 당일 누적
W = valuewhen(1, date!=date(1), Q(1));
E = Q - W;                                     // 당일 실시간 누적거래대금

DD = !상한가체크(1) and UL() and E >= [대금];   // "신규" 상한가 발생 + 대금조건 충족
D  = CountSince(DD, Date != Date(1));           // DD 이후 경과일수
A  = ValueWhen(1, DD, DayHigh());               // 상한가일 고가 = R0 기준값
B  = ValueWhen(1, DD, PreDayclose());           // 상한가 발생 전일 종가 = R3
AB = (A-B)/3;

R0(수식1) = if(D < 기간+1, A, 0);
R1(수식2) = if(D < 기간+1, A-AB, 0);
R2(수식3) = if(D < 기간+1, (A-(AB*2)), 0);
R3(수식4) = if(D < 기간+1, (A-(AB*3)), 0);
```
- **대금 조건값 = 500** (억원, 15분봉 이상은 400억 권장 — 3번 항목 참고), **기간 = 7** (7일 이후 신호 소멸, 규칙 4번과 정합)
- "상한가리바운딩(선)" 변형: 기간 경과 후 값을 0 대신 `(A+B)*0.5`로 대체해 선을 계속 표시하는 시각화 옵션(로직은 동일, 표시 방식만 차이)

**보조: 선취매(사전 스크리닝) 검색식** (커뮤니티 제공, SR 진입 후보를 "상한가 발생 이전"에 찾기 위한 보조 도구)
```
A: 1일전까지 1일간 연속상한가 (배제조건, !A로 사용)
B: 신고가[일]1봉전 고가가 120봉이내 120봉 신고가 발생
C: 신고가[일]0봉전 고가가 120봉중 신고가
D: [일]거래대금(일:백만,분:천) 300000이상 1000000000이하
E: 주가등락률[일]1봉전(중) 종가대비 0봉전 종가등락률 10%이상
F: 주가등락률[일]0봉전(중) 시가대비 0봉전 종가등락률 9%이상
G: 주가이평비교[주]0봉전 (종가1)이평 > (종가60)이평 1회이상
H: 주가이평비교[주]0봉전 (종가1)이평 > (종가120)이평 1회이상
I: [일]0봉전 일목균형표(9,120,52) 주가 > 기준선

최종식: !A and B and C and D and E and F and (G or H) and I
```

**거래대금 계산 오차 관련 유의사항**: 키움 HTS가 분봉 단위 거래대금 함수를 직접 제공하지 않아 "OHLC 평균×거래량" 근사식을 사용하며, 분봉이 길수록 오차가 커진다. 1분봉에서는 500억이 정상 범위로 보이나, 15분봉 이상에서는 같은 종목이 400억 설정에서만 표시되는 등 캔들 주기에 따라 조건값을 다르게 적용해야 한다.

## 4. 계산기(xlsx) 로직

`상한가리바운딩수동입력기.xlsx` — "리바운딩" 시트, 단순 3등분 계산기:
```
C = 현재가 (R0, 상한가 종가)
D = 전일비 (상한가 상승폭)
E(R3) = C - D                      // 전일종가
F(R1) = C - ((C - E) / 3)          // 1차 등분선
G(R2) = F - ((C - E) / 3)          // 2차 등분선
```
이론 수식(A, AB=(A-B)/3, R1=A-AB, R2=A-2AB)과 완전히 동일한 로직을 엑셀로 재현한 것 — MTS(모바일)로만 매매할 때도 계산기 하나로 충분히 실행 가능함을 보여주는 자료.

## 5. 실전 사례 요약 (2021년 5월~9월 복기 자료 샘플 기반, 500건 이상 관측)

- **결과 라벨 분포**: "R1본절"(R1에서 매수 후 본전 청산), "R1손절"/"R2손절"/"R3로스컷"(규칙대로 손절 실행), "R1"/"R2"(수익 실현) 등이 혼재 — 이론상 손절 규칙(R3 도달시)이 실제로 자주 발동되며, 승률이 100%가 아님이 실거래로 확인됨
- **"안함"(매수 보류) 판정 사유 빈도순**: 날짜오버(상한가 후 7일 초과) > 무공방 > 긴N자상한가 > 단기과열 > 동테마/후발주 > 유증무증권리락 > 관리종목/악재
- **예외 규정 실증**: "시장중심주"로 분류된 경우, 위 배제 사유가 있어도 실제로 매매를 진행한 사례가 다수 관찰됨 (예: 삼성제약/동양/SM C&C 등에 "시장중심주" 태그와 함께 배제 사유 무시하고 진행)
- **실패 사례 코멘트 (강사 직접 서술)**: 한 종목에서 장마감 후 인수 무산설(악재)이 나와 다음날 하한가 급락 — "혹시 매수후 알았더라면 손절했어야했을거같네요"라는 코멘트. 갭하락 리스크에 대한 구조적 취약점을 시사
- **"원칙준수와의 싸움"**: 강사가 직접 "무손실로 구경한 것만으로도 감사"라고 언급 — 기계적 규칙을 지키는 것이 심리적으로 쉽지 않다는 점을 인정

## 6. 강사가 강조한 주의사항 및 리스크

**SR 전용 배제 리스트** ("SR은 긴 무당똥 유후홀" 니모닉 — 회피 대상):
| 패턴 | 의미 | SR 처리 |
|------|------|--------|
| 긴N자상한가 | 급등 후 조정 없이 재상승한 긴 N자형 | ❌ 회피 |
| 무공방 | 상한가 전 매물대(저항) 공방 없이 직행 | ❌ 회피 |
| 단기과열 | 거래소 단기과열 지정 종목 | ❌ 회피 |
| 동테마(후발주) | 테마 대장주가 아닌 동반 상승 후발주 | ❌ 회피 |
| 유증무증권리락 | 유상/무상증자 권리락 구간 | ❌ 회피 |
| 홀짝매매 | (강사 고유 패턴 판단 규칙) | ❌ 회피 |

**SR에서는 예외적으로 허용/조건부인 패턴** (K1/K2 등 다른 기법과 차별화):
- 역망치(익일봉) — SR에서는 O (허용). K1에서만 금지
- 갭뜬상한가 — SR에서는 "세모"(조건부, 케이스별 판단)
- 쌍봉상한가 — 조건부(△)

**공통 예외 규정**: "# 시장중심주는 이 모든것을 무시하고 다 되는편입니다" — 시가총액/거래대금/시장 주도력이 확실한 종목은 위 배제 리스트를 적용하지 않는 재량 판단이 존재.

**운영상 주의사항 (Kiwoom HTS 실행 기준)**:
- 조건검색 감시가격 설정 시 **부등호 방향(≤/≥) 오류 주의** — 반대로 설정하면 고가에 잘못 매수됨
- 장마감 후 **단기과열 지정 여부**를 확인하고 해당 시 예약주문 일시정지
- 자동매도(잔고편입 자동매도) 설정 시 목표수익률(예 5%) 도달시 절반 정리 등 사전 설정 가능
- **키움 서버 조건주문 유효기간 = 90일** — 주기적으로 최대 날짜로 갱신 필요. 누락 시 매도가 실행되지 않는 사고 발생 가능

## 7. 전문가 검토

### 7.1 technical-analyst 관점

이 기법이 근거하는 가격 되돌림 그리드(R0~R3, 1/3·2/3 등분)는 시장에서 흔히 관찰되는 되돌림(retracement) 현상과 부합하며, 상한가는 강한 수급 쏠림의 명확한 증거이므로 되돌림 구간에서 지지를 노리는 논리 자체는 타당하다. 다만 현재 SR은 **순수 가격 그리드만 사용하고 보조지표를 전혀 결합하지 않는다** — R1/R2 터치 시점에 RSI 과매도 여부, 거래량 급감(매도세 소진) 여부를 함께 확인하면 "진짜 지지"와 "그리드 붕괴"를 구분하는 데 도움이 될 것이다. 보조 스크리닝 공식(선취매)에 사용된 120봉 신고가+등락률+이평 정배열+일목균형표 기준선 조합은 모멘텀 스크리너로서 합리적이다. 등분선 그리드는 **정적 기준**이라 코스피/코스닥 전체 하락장에서는 쉽게 무너질 수 있어, 매크로 국면(quant/macro 판단)과 결합해 적용 여부를 조절할 필요가 있다.

### 7.2 quant-strategist 관점

진입(R1 또는 R2 추가매수)과 청산(R0 분할매도 / 4일 강제청산 / R3 손절)이 명확히 수치화되어 있어 **시스템 트레이딩으로 규칙화하기 매우 좋은 기법**이다. 파라미터 수도 적어(등분수=3, 유효기간=7일, 보유기간=4일, 대금기준 1개) 과최적화 위험은 낮은 편이나, 이 숫자들 자체의 근거가 문서화되어 있지 않으므로 다른 값(5등분, 5일 보유 등)에 대한 민감도 분석이 필요하다. **백테스팅 설계 제안**: 유니버스=일별 상한가(당일고가=당일종가) 전 종목, 대금필터 400~500억, 진입 R1/R2 터치, 청산 로직 그대로 시뮬레이션, 벤치마크는 코스피/코스닥 지수 및 "무필터 상한가 전량 매수" 대비 초과수익. 실거래 복기 자료에서 R1손절/R3로스컷 사례가 다수 관찰되므로 **승률·손익비를 반드시 실측 데이터로 검증**해야 하며(현재는 이론적 근거만 있고 샤프비율·MDD 등 정량 성과지표 문서 없음), 정성적 배제 필터(무공방/긴N자/동테마 등)는 자동화 시 가장 큰 도전 과제다.

### 7.3 risk-manager 관점

**손절 규칙(R3 도달시)이 명시적으로 존재**하는 점은 긍정적이나, R1 매수 기준 R3까지의 손실폭은 (R0-R3)의 2/3에 해당해 — 상한가 자체가 통상 +15~30%이므로 실제 손절폭은 상당히 클 수 있다(포지션 기준 -10~20%대 가능) → **포지션 사이징이 반드시 병행되어야 하며, 문서에는 이 부분에 대한 명시적 규칙이 없다**. 최대 4일 보유기간은 리스크 노출시간을 제한하는 장점이 있으나 **갭하락(장 시작 전 악재) 리스크에는 무방비**하며, 실제로 장마감 후 악재로 다음날 하한가 급락한 사례가 복기 자료에서 확인된다 — 이는 구조적 약점으로 반드시 명시해야 한다. 예시된 포지션 규모(10억 계좌 대비 3천만원=3%)는 합리적이나 추가매수(R2, 1:1)까지 고려하면 최대 노출이 초기 대비 2배(약 6%)까지 확대되는데 이에 대한 상한선이 문서화되어 있지 않다. 자동매매 특유 리스크로 (1) 예약주문 90일 만료로 인한 매도 누락, (2) 단기과열 지정 등 제도적 리스크의 장중 실시간 감시 필요, (3) "시장중심주는 예외"라는 재량 판단 요소가 남아있는 한 완전 무인 자동화는 리스크 관리 사각지대를 만들 수 있다.

**종합 평가: 🟡 조건부 활용 가능.** 정량적 규칙(R0-R3 계산, 7일/4일 규칙, 손절가)은 자동화에 적합하나, 정성적 배제 필터와 "시장중심주" 예외 판단은 사람의 재량이나 별도 패턴인식 모델이 필요하므로, 완전 무인 자동매매보다 **"신호 생성은 자동화 + 최종 승인은 수동"인 반자동 방식으로 시작**할 것을 권장한다.

**fundamental-analyst / macro-strategist는 검토 대상에서 제외**: SR은 개별 종목의 단기 가격/수급 패턴에만 의존하는 순수 기술적 기법이며, 재무제표 분석이나 거시경제 변수를 직접 활용하지 않기 때문이다.

## 8. 자동매매 구현 시 고려사항 / 미해결 질문

1. **정성적 배제 필터(무공방/긴N자/동테마/후발주 등)를 규칙 기반으로 어떻게 코드화할 것인가** — 근사 규칙(상한가 도달까지 캔들 수, 장중 되돌림 비율 등)을 정의하거나, 완전 자동화 대신 사람 승인 단계를 두는 하이브리드 구조 검토 필요
2. **"시장중심주" 판단 기준이 문서에 정량화되어 있지 않음** — 시가총액, 거래대금 순위, 테마 내 최초 상한가 여부 등으로 근사 규칙화 필요
3. **실시간 거래대금 계산 오차** (분봉 단위별 근사 오차) — API 상 정확한 체결 기반 거래대금 데이터 소스 확보 필요 (근사식 대신)
4. **예약매수/자동매도 브로커 API 연동 방식 확정** (키움 Open API+ 등) 및 **조건주문 90일 만료 자동 갱신 로직** 구현 필수
5. **정량적 백테스트 미실시** — 실측 성과지표(승률, 손익비, MDD) 산출 전까지는 소액/모의투자로 우선 검증 필요
6. 뉴스성 재료(테마)의 "지속성" 판단은 별도 뉴스/공시 모니터링 모듈과 결합 필요 (fundamental-analyst 영역과 연계 가능)
7. 단기과열 지정, 관리종목 지정 등 **제도적 리스크에 대한 장중 실시간 필터링 로직** 별도 구현 필요
