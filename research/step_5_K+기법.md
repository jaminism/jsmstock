# Step 5 — K+기법 (K1플러스 / K2플러스)

## 1. 기법 개요

**"세력봉"** 출현을 트리거로, 세력봉 직전 RSI 과매도 구간~세력봉(또는 그 직전) 고점까지 5분봉 기준 피보나치 되돌림선(0.236, 0.5)을 긋고, 그 되돌림선을 하향 이탈("훼손")하는 시점을 진입 신호로 삼는 기법. K1/K2 기법의 "심화·정량화 버전(플러스)"으로, 원조 K1/K2가 상한가 이후의 여러 재량적 차트 조건에 의존했다면 K+는 **"세력봉" 수식 정의 + 피보나치 되돌림**이라는 좀 더 규칙화된 트리거 체계를 사용한다.

- **K1플러스** = 종가베팅(스윙 성격, 세력봉 당일 종가 매수)
- **K2플러스** = 장중매매(당일 즉시 매수, 종가를 기다리지 않음)

> ⚠️ "당일양봉종가베팅(세력봉당일매수) = K1플러스매매"는 **"양봉종가베팅(상한가 다음날 매수)"이라는 별개 기법과 명확히 다르다**고 원문에서 강조함(교재 10p 도식으로 시각적으로도 구분).

## 2. 핵심 진입/청산 규칙

### K1플러스 (종가베팅)
- **진입**: 500억 이상 대금의 세력봉 출현 시, 세력봉 직전 RSI 과매도~세력봉 고점까지 피보나치(5분봉)를 긋고 0.236선(K1+)을 하향 이탈하면 **세력봉 당일 종가**에 매수
- **청산(익절)**: +4% ~ 직전 고점까지 분할매도
- **보유기간**: 매수는 당일만 유효, **매수 4일차에는 전량매도(무조건)**
- **손실 대응(-7%)**: 시장중심주(대장주)일 경우만 추가매수 가능, 단순 개별종목이면 손절

### K2플러스 (장중매매)
- **진입**: 세력봉 직전 RSI과매도~세력봉 직전 고점까지 피보나치, 0.5선(K2+) 하향 이탈 시 **장중 즉시** 매수
- **청산(익절)**: +4% ~ +7% 구간 분할매도
- **매수 가능 기간**: 고점 갱신일 포함 4일차까지
- **손실 대응(-7%)**: 대상 종목이 1등주(주도주)가 아니면 1등주 흐름을 보고 손절 또는 추매를 재량 판단

### 기법별 "-7% 추매 가능 대상" (원문 표, 5장 자료)
| 기법 | 추매 가능 대상 |
|------|---------------|
| SR | 시장중심주, 1등주, 2등주, 개별테마주 |
| K1 | 시장중심주, 1등주, 개별테마주 |
| K2 | 시장중심주, 1등주, 2등주, 개별테마주 |
| **K1+** | **시장중심주만** (가장 보수적) |
| K2+ | 시장중심주, 1등주, 개별테마주 |

→ K+ 시리즈, 특히 K1+는 원조 K1/K2보다 추매 허용 범위가 좁아 리스크 관리가 더 엄격함.

## 3. 검색식/스크리닝 공식 (원문)

HTS "수식관리자 → 강세약세 → 사용자강세약세"에 등록하는 커스텀 지표(`#세력봉`):

```
A = 거래대금 >= 세력봉대금*100 and C(1)*1.15 <= H and L*1.15 <= H and O*1.09 <= C;
AA = 거래대금 >= 상한가대금*100;
고점일 = highest(h(1), 고가기간);
if(UL(), AA, A);
```

약세(제외) 패턴:
```
!상한가체크(1) and 고점일 <= H and UL() and AA;
```

- 노란색 = 120일 신고가를 동반한 특별한 상한가만 표시
- 분홍색 = 120일 신고가는 아니지만 세력봉/상한가 조건을 만족하는 일반 케이스

조건검색식(0150)에 등록 후 0156 화면에서 실시간 검색 가능(MTS도 가능)이라고 원문에 명시.

**🔴 미확정 사항**: `세력봉대금`, `상한가대금`, `고가기간` 파라미터의 실제 수치는 "지표변수에 들어가 다음과 같이 적고"라는 설명뿐, 실제 숫자는 화면 캡처 이미지 안에 있어 텍스트 추출로 확인되지 않음. **자동매매 구현 전 반드시 확인 필요** (원본 mp4 강의 영상에 나올 가능성 있음).

## 4. K1/K2 대비 개선/추가된 점

- 원조 K1/K2(step_2, step_3)는 상한가 이후 여러 차트 조건(공방, N자 형태 등)에 의존하는 재량적 판단 비중이 컸음
- K+는 "세력봉" 수식 + 피보나치 되돌림이라는 정량적 트리거를 결합해 진입 시점을 좀 더 규칙화
- 다만 "시장중심주/1등주/2등주" 판별은 여전히 재량적 — 완전 자동화의 병목 지점

## 5. 실전 사례 요약 (약 60개 종목 사례 중 대표 패턴)

- **돌파종베**: 매물대 횡보 후 거래량이 줄어들며 전고점을 재돌파하는 지점에서 종가매수 — 이론 규칙보다 실전에서 훨씬 빈번하게 등장하는 응용 변형
- **트레일링 라인**: 3일선을 지지하는 동안 "무한종베"(반복 종가매수) 지속, **5일선 이탈 시 일괄 손절**이 실질적인 트레일링 스탑 규칙으로 반복 사용됨
- **패턴 오인 사례**(케이티알파): 처음엔 "긴 N자"로 오인했으나 추세 확인 후 매집으로 재해석 — 패턴 분류가 기계적으로 항상 명확하지 않음을 강사 스스로 인정
- **손절 실행 사례 다수**: "쌍봉으로 파악, 바로 손절", "5일선 깨지면서 손절처리", "반등없이 밀릴 시 미련없이 손절" — 규칙 기반 손절이 실제로 반복 실행됨
- **매횡상**(매물대 횡보 후 상승) 패턴: 이슈/재료가 지속되는 동안에만 "무한 종반꿀"(반복 익절) 가능 — 기술적 신호에 펀더멘털적 판단(이슈 생존 여부)이 선행 조건으로 개입

## 6. 강사가 강조한 주의사항 및 리스크

- **회피 패턴 목록**(88~89p, 124~156p 차트 유형 갤러리): 단기과열, 무공방, 동일테마 후발주, 역망치(K1 한정 금지), 갭뜬 쌍봉상한가, 유상증자/무상증자/권리락 임박 종목, 후발주 — "안돼요"라고 명시적으로 경고. 단, 세부 시각적 기준은 차트 이미지 위주라 텍스트만으로 완전 재현은 어려움(taxonomy 이름만 확보됨)
- **계좌관리(행동 수칙)**: 관심종목 수익률을 계속 들여다보지 않기, 평가손익(미실현 손익) 창을 보지 않기 — 감정적 매매 방지 목적. *자동화하면 이 문제 자체가 구조적으로 해소됨*
- **욕심 관리**("새력봉만들기.docx" 원문): "고니처럼 딴돈의 반만 가져간다" — 수익 구간 진입 시 최소 절반은 반드시 익절 확정하는 규율. "다이아몬드스텝매매"(K1+K2 매수매도 결합), "역삼각매매"(1회 추가매수 후 첫 매수가에서 매도, 즉 손익분기 탈출) 개념 언급 (상세 정의는 자료 범위 밖, 7강 응용매매에서 다룬다고 언급됨)

## 7. 전문가 검토

### 7.1 technical-analyst 관점
- 세력봉 수식(거래대금 급증 + 시가 대비 종가 +9%↑ + 저가/전일종가 대비 고가 +15%↑)은 실질적으로 **"거래량 동반 브레이크아웃"**을 포착하는 필터로, 표준 기술적 분석 프레임에 부합하는 타당한 근거를 가짐
- 피보나치 되돌림을 진입 트리거로 쓰는 방식은 본질적으로 **"모멘텀 후 얕은 되돌림 매수(pullback buy)"** 전략 — 검증된 기법 범주에 속함. 거래대금·캔들형태·피보나치 되돌림, 3개 이상 지표를 교차 사용한다는 점에서 원칙 충족
- 약점: 손절이 ATR/변동성 기반이 아닌 **정률(-7%) 고정** — 저변동성 대형주와 고변동성 테마주에 동일 기준을 적용하면 리스크 불균형 발생 가능
- `고가기간` 등 핵심 파라미터 수치 미확정 상태로는 신호 재현 불가

### 7.2 quant-strategist 관점
- "모멘텀 + 눌림목 진입" 하이브리드로 분류 가능, 이론적 근거는 있는 편
- 진입조건은 수식이 존재해 규칙화 가능하나 파라미터 미확정 문제 해결이 선행 과제. 청산조건(분할매도, 4일 보유제한, -7%/추매)은 비교적 명확 — 3요소(진입-청산-리스크관리) 중 진입 파라미터만 보완되면 시스템화 가능한 수준
- **백테스팅 유의점**: 자료가 2021년 국내 소형주 급등장(테마주 활황기) 데이터에 집중 — 하락장/횡보장 구간 검증 없이는 **과최적화 위험 높음**. "종산기법 유형별 성공률" 페이지가 존재하나 실제 수치는 이미지 안에 있어 텍스트로 확인 불가 → 승률 근거 자체가 미검증 상태
- "거래대금 급증 + 장대양봉 + 신고가 갱신" 조건은 모멘텀·거래량 팩터 조합으로 재정의해 자동 스크리닝으로 치환 용이

### 7.3 risk-manager 관점
- 🔴 `세력봉대금`/`상한가대금`/`고가기간` 파라미터 수치 미확정 — 이 상태로는 자동매매 코드로 옮길 수 없음. 확인 필수
- 🔴 손절 규칙은 존재(-7%, 5일선 이탈)하나 **계좌 전체 관점의 손실 한도, 1회 베팅 규모 기준**이 자료에 없음 — 개별 종목 매매일지 중심이라 포트폴리오 분산 개념 부재. fund-manager 단계에서 계좌 단위 집중도 한도를 별도로 씌워야 함
- 🟡 "추매" 조건이 재량적(대장주 여부 판단) — 자동매매에서는 정량 기준(등락률/거래대금 순위 등)으로 치환 필요
- 🟡 4일 보유 제한의 세부 실행 시점(4일차 시가/종가 등)이 불명확 — 명확화 필요
- 🟢 "수익의 절반은 반드시 실현" 철학은 리스크 관리 관점에서 바람직 — "+X% 도달 시 50% 익절" 규칙으로 코드화 가능
- fundamental-analyst/macro-strategist는 이 기법과 무관(개별 종목의 단기 차트·거래량 패턴 기반 순수 기술적 기법이며 재무제표 밸류에이션이나 거시경제 변수를 다루지 않음)하여 이번 검토에서 제외

## 8. 자동매매 구현 시 고려사항 / 미해결 질문

1. **세력봉 수식 파라미터**(세력봉대금, 상한가대금, 고가기간) 실제 수치 확인 필요 — 원본 mp4 강의 영상에 언급됐을 가능성 있음
2. "시장중심주/1등주/2등주" 자동 판별 로직 필요 — 동일 업종·테마 내 등락률·거래대금 순위 기반 설계 검토
3. 피보나치 되돌림 자동 계산(RSI 과매도~고점 구간 자동 탐지) 구현 필요
4. 국내 증시 특유 제도(상한가/하한가 가격제한폭) 반영 — 사용할 시세/주문 API 확정 필요
5. 2021년 급등장 외 다른 시장국면(하락장 등) 데이터로 별도 백테스트 검증 필수
6. 회피 패턴(무공방, 역망치 등)의 시각적 판별 기준을 코드화하려면 차트 이미지 기반 별도 정의 작업 필요(텍스트 자료만으로는 taxonomy 이름만 확보됨)
